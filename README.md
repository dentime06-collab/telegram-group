# Telegram Group Sender

Русский настольный интерфейс для публикации обычного текста через Telethon (MTProto). Каждая отправка и каждое вступление требуют отдельного подтверждения. Техническое право отправки не означает разрешения по правилам группы: это подтверждает сам пользователь.

## Получить приложение на Windows через GitHub Actions

1. Создайте репозиторий GitHub. Загрузите **содержимое этой папки**, включая `.github/workflows/macos.yml`, в корень репозитория. Не загружайте личные API-ключи и сессии.
2. Откройте Actions → macOS application → Run workflow → Run workflow. При необходимости включите Actions для репозитория.
3. После успешного завершения обеих задач скачайте Artifacts: `TelegramGroupSender-arm64` и `TelegramGroupSender-x86_64`.
4. Распакуйте скачанный контейнер артефакта. Внутри находится `TelegramGroupSender-arm64.zip` или `TelegramGroupSender-x86_64.zip` с настоящим `.app`, а также SHA-256. Передайте нужный ZIP человеку с Mac.
5. На Mac: «Об этом Mac» → чип Apple M… означает arm64; процессор Intel означает x86_64. Распакуйте ZIP и перенесите `.app` в «Программы».

Python и библиотеки включаются в `.app`. Две нативные сборки используются вместо рискованного склеивания Qt/Python через lipo. Целевая проверяемая среда — macOS 15 и новее; более старые версии не заявлены. Запуск workflow может расходовать квоту GitHub Actions, особенно в приватном репозитории.

**В этом исходном архиве нет собранного `.app`.** Сборка должна завершиться на macOS runner. Публикация репозитория и запуск Actions не выполняются автоматически из этого архива.

## Первый запуск

Получите собственные API ID и API Hash на https://my.telegram.org → API development tools. Введите их и нажмите «Подключиться». Для нового входа укажите номер в международном формате, нажмите «Получить код», введите код и при необходимости пароль 2FA. При следующем запуске нажмите «Подключиться»: сохранённая сессия восстановится.

Вставьте публичные ссылки, @имена или приглашения `https://t.me/+…` / `https://t.me/joinchat/…`. Нажмите «Проверить группы». При необходимости выделите строку и подтвердите вступление. Заявка в закрытую группу требует одобрения администратора; после него повторите проверку. Каналы, личные чаты и ссылки на отдельные сообщения не поддерживаются.

Отметьте доступные группы, введите текст, просмотрите его и нажмите «Начать». В каждом диалоге проверьте группу и сообщение и подтвердите отправку. «Отмена» приостанавливает очередь; «Продолжить» возвращает подтверждение. «Остановить» прекращает дальнейшие операции; уже переданный серверу запрос отозвать нельзя. Текст очереди фиксируется при нажатии «Начать». Для нового текста завершите текущую очередь либо перезапустите приложение.

FloodWait блокирует последующие запросы до истечения указанного срока. Ошибка останавливает очередь; автоматических повторов отправки нет. После ошибки текущая группа удаляется из очереди: для повторной попытки заново выберите её в новом запуске очереди. При таймауте сначала проверьте чат — сообщение могло быть доставлено. После перезапуска очередь не восстанавливается. Повторная попытка с тем же текстом вызывает дополнительное предупреждение в подтверждении, включая незавершённые попытки.

## Хранение и конфиденциальность

API Hash и строковая сессия хранятся в системном macOS Keychain через keyring, а не в открытом `.session`. Keychain может запросить разрешение доступа. Пароль 2FA и код не сохраняются. Данные сессии в памяти нужны Telethon для работы; Keychain не защищает от уже скомпрометированного аккаунта macOS.

История находится в `~/Library/Application Support/TelegramGroupSender/history.sqlite3`: время UTC, ID группы, хеш текста, статус и краткая причина. Текст и коды не записываются. Папка создаётся с правами 0700, файлы — с umask 077. CSV содержит эти же поля и защищает формулы электронной таблицы. CSV после экспорта храните как личный файл. В видимом журнале могут присутствовать названия групп. Приватные ссылки и текст не записываются на диск приложением.

Для отзыва доступа завершите сессию в Telegram → Настройки → Устройства. Для удаления локальных секретов используйте «Связка ключей»: сервис `TelegramGroupSender`, записи `session`, `api_id`, `api_hash`; удалите также папку истории. Передача ZIP не передаёт ваш аккаунт.

## Gatekeeper, подпись и нотариализация

По умолчанию PyInstaller делает ad-hoc подпись, необходимую для целостности arm64. Это **не** подпись доверенного разработчика Apple и не нотариализация. Gatekeeper может блокировать приложение. Не отключайте Gatekeeper глобально. Если вы доверяете источнику и проверили архив, используйте штатное «Конфиденциальность и безопасность → Всё равно открыть», если macOS предлагает этот вариант.

Для распространения с Developer ID добавьте GitHub repository secrets:

- `MACOS_CERTIFICATE_P12_BASE64`: base64 сертификата Developer ID Application с приватным ключом (.p12).
- `MACOS_CERTIFICATE_PASSWORD`: пароль .p12.
- `MACOS_SIGNING_IDENTITY`: полное имя `Developer ID Application: … (TEAMID)`.
- `NOTARY_APPLE_ID`, `NOTARY_TEAM_ID`, `NOTARY_PASSWORD`: Apple ID, Team ID, специальный пароль приложения Apple для notarytool.

Все шесть значений должны соответствовать одному действительному аккаунту Apple Developer. Workflow импортирует сертификат во временную связку, подписывает, отправляет ZIP на нотариализацию, прикрепляет ticket, проверяет stapler/spctl и заново создаёт ZIP. Ошибка нотариализации завершает сборку ошибкой. Если задать только подпись, результат будет подписан, но не нотариализован. Без реального сертификата и успешной нотариализации отсутствие предупреждений не обещается.

## Разработка и проверки

Требуется Python 3.12. На macOS:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m pip check
python -m pytest -q
python main.py
bash scripts/build_macos.sh
```

Проверка GUI без авторизации: `QT_QPA_PLATFORM=offscreen python main.py --smoke-test`. Сборочный скрипт также запускает упакованный executable в smoke-режиме и проверяет codesign. Это не заменяет реальный вход и доставку на тестовом Telegram-аккаунте.

Сетевые вызовы выполняются в отдельном потоке с одним asyncio loop. GUI получает результаты через Qt signals. Очередь хранится в памяти, журнал попытки фиксируется до сетевого запроса. Повторные MTProto-запросы на уровне клиента отключены (`request_retries=0`); собственных обходов антиспама, автоматического вступления или бесконтрольной рассылки нет.

Ограничения: предпросмотр — обычный текст без Markdown/HTML, вложения не поддерживаются. Telegram может изменить права, включить slow mode, платные сообщения или ограничить аккаунт между проверкой и отправкой — окончательное решение принимает сервер. Приложение не обещает доставку или отсутствие блокировок. Для forum-групп отдельный выбор темы не реализован.

Зависимости имеют собственные лицензии: Telethon (MIT), PySide6/Qt (LGPL/GPL/commercial), keyring (MIT), PyInstaller с исключением для собираемых приложений. Перед коммерческим распространением обеспечьте выполнение условий Qt, включая уведомления и возможность замены библиотек; onedir сохраняет динамические библиотеки отдельными файлами.
