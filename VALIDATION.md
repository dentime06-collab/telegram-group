# Выполненные проверки

Среда: Linux x86_64, Python 3.12.14.

- Установлены все зависимости requirements-dev.txt, включая Telethon 1.45.0 и PySide6 6.10.2.
- `python -m pip check`: No broken requirements found.
- `python -m pytest -q`: 17 passed.
- `QT_QPA_PLATFORM=offscreen python main.py --smoke-test`: код завершения 0. Предупреждение offscreen-плагина Qt о propagateSizeHints не препятствовало запуску.
- Компиляция исходников Python и `bash -n scripts/build_macos.sh`: успешно.

Тесты покрывают нормализацию и дубликаты ссылок, недопустимые ссылки, сохранение незавершённой попытки между запусками, CSV и защиту от формул, проверку ограничений на текст, отсутствие повтора при таймауте, FloodWait, отмену подтверждения, остановку очереди и предупреждение о дубликате.

НЕ выполнено: реальная авторизация Telegram, 2FA на аккаунте, вступление/отправка через сеть, проверка macOS Keychain на Mac, сборка и запуск .app на Intel/Apple Silicon, подпись действительным Developer ID, нотариализация. GitHub Actions подготовлен, но в рамках этой поставки не запускался. Перед передачей конечному пользователю необходимо дождаться успешных двух macOS jobs и проверить вход/одну согласованную отправку на тестовом аккаунте.
